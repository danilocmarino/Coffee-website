
# Dark Coffee Website

## About the Project

Dark Coffee is a responsive coffee shop website
created for the Web Development II refresher task.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive website layout
- Dark theme with gold accents
- Coffee menu with product images
- Interactive coffee category filters
- Navigation between page sections

## Testing

The website was tested at desktop (1440px)
and mobile (375px) screen widths.

The coffee filters were tested to confirm
that the correct products are displayed.

## Reflection

Creating the Dark Coffee website was a useful
opportunity to refresh my HTML, CSS and JavaScript
skills. I found creating the HTML structure and
organising the different sections of the website
relatively straightforward. I also enjoyed styling
the page with a dark colour scheme and using CSS
Grid to organise the coffee menu.

One of the main challenges I faced was adjusting
the product images because some of them were not
displaying correctly. I had to experiment with CSS
properties such as object-fit and object-position
to improve their appearance.

I also practised using JavaScript to create
interactive buttons that filter coffee products
by category.

During Web Development II, I would like to improve
my JavaScript skills and become more confident in
creating responsive and interactive websites
independently.
